# 信息安全工程师教程（第2版）精校版

本项目基于《信息安全工程师教程（第2版）》官方教材扫描件进行精校整理，便于学习与查阅。精校版文件请在 **Releases** 中下载；如发现图片、公式等异常，请根据仓库中的 `专项校对索引.csv` 定位到扫描件对应位置进行核对。

## 下载

- **精校版**：请前往 [Releases](https://github.com/MrKQA/Information-Security-Engineer-Tutorial-2nd-Edition-/releases) 下载最新版本。

## 校对说明

- 精校版会尽量修正文字、排版、图片和公式中的问题。
- 如发现 **图片或公式上的错误**，请先查阅 [专项校对索引.csv](./专项校对索引.csv)，按索引记录查看原文件对应位置。
- 请以扫描件对应位置为最终核对依据；确认问题后欢迎提交反馈。
- 索引文件用于辅助定位，具体字段与记录以仓库内实际文件为准。
